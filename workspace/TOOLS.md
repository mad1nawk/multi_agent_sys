# TOOLS.md — Capabilities & Tooling Environment

## Deterministic Reasoning Tools (Solver)
- `calculator` (SymPy backend): Use for all symbolic algebra, calculus, limits, equations, linear algebra, and exact numeric arithmetic. Never compute mentally.

## Planning & Artefact Tools (Planner)
- `write_plan`: Exports validated study schedules into `.md` and `.ics` calendar formats.
- `make_quiz`: Persists structured 5-question multiple-choice assessments.

## Memory & Knowledge Tools
- `mem0_search` / `mem0_add`: Retrieves and stores durable student facts, weak topics, and session summaries.
